# 🎬 一期一会のウラオモテ

映画の深層と、ビジネスの効率化が交差するハイブリッドブログ

## 📋 プロジェクト概要

このプロジェクトは、Astroフレームワークを使用して構築された2カラムレイアウトのブログサイトです。映画考察とビジネス/せどりに関するコンテンツを提供します。

## 🛠️ 技術スタック

- **フレームワーク**: Astro 5.17.1
- **スタイリング**: Tailwind CSS 4.1.18
- **パッケージマネージャー**: pnpm
- **デプロイ**: Netlify
- **バージョン管理**: Git / GitHub

## 🚀 開発環境のセットアップ

### 前提条件

- Node.js 22.x
- pnpm 10.x

### インストール手順

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev

# ビルド
pnpm build

# ビルドのプレビュー
pnpm preview
```

## 📁 プロジェクト構造

```
hybrid-blog/
├── src/
│   ├── components/
│   │   └── Sidebar.astro          # サイドバーコンポーネント
│   ├── layouts/
│   │   └── Layout.astro           # ベースレイアウト
│   ├── pages/
│   │   ├── index.astro            # ホームページ
│   │   └── articles/
│   │       └── sliding-doors.astro # 記事ページ
│   └── styles/
│       └── global.css             # グローバルスタイル
├── public/                         # 静的ファイル
├── astro.config.mjs               # Astro設定
├── netlify.toml                   # Netlify設定
└── package.json
```

## 🎨 主な機能

### レイアウト

- **2カラムレスポンシブデザイン**: デスクトップでは2カラム、モバイルでは1カラムに自動調整
- **サイドバー**: プロフィール、人気記事、カテゴリー、検索機能を含む

### コンテンツ

- **記事ページ**: Markdownベースのコンテンツ管理
- **メルカリショップ連携**: 各記事の最後に自動生成されるCTAボタン
- **カテゴリー分類**: 映画考察、ビジネス/せどり、ツール開発

### デザイン

- **モダンなUI**: Tailwind CSSによる洗練されたデザイン
- **カードレイアウト**: 記事一覧はグリッドカードで表示
- **ホバーエフェクト**: インタラクティブなUI要素

## 🌐 デプロイ

### Netlifyへのデプロイ

1. GitHubリポジトリと連携
2. ビルド設定:
   - Build command: `pnpm install && pnpm build`
   - Publish directory: `dist`
   - Node version: 22

詳細は `NETLIFY_DEPLOY_INSTRUCTIONS.md` を参照してください。

## 📝 記事の追加方法

新しい記事を追加するには：

1. `src/pages/articles/` に新しい `.astro` ファイルを作成
2. 既存の記事（例: `sliding-doors.astro`）をテンプレートとして使用
3. フロントマターとコンテンツを編集
4. `src/pages/index.astro` の記事一覧に追加

## 🔧 カスタマイズ

### サイドバーの編集

`src/components/Sidebar.astro` を編集して、プロフィール情報やカテゴリーを変更できます。

### スタイルの変更

`src/styles/global.css` でグローバルスタイルを、各コンポーネント内の `<style>` タグでコンポーネント固有のスタイルを編集できます。

### メルカリリンクの変更

記事ページの最後にあるメルカリショップへのリンクは、各記事ファイル内で直接編集できます。
